# Claude Code 配置指南

## 配置文件层级

```
┌─────────────────────────────────────────────────────────────┐
│                    配置优先级（从高到低）                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. managed-settings.json    （企业强制配置，优先级最高）      │
│     ├── C:\Program Files\ClaudeCode\managed-settings.json   │
│     └── /etc/claude-code/managed-settings.json              │
│                                                             │
│  2. ~/.claude/settings.json     （用户级配置）                │
│     └── 全局生效，覆盖所有项目                                │
│                                                             │
│  3. .claude/settings.json       （项目级配置）                │
│     └── 仅当前项目生效，优先级高于用户配置                      │
│                                                             │
│  4. .claude/settings.local.json  （项目本地配置）              │
│     └── 仅当前项目，gitignored，优先级最高                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 3. 权限配置 (permissions)

```
┌─────────────────────────────────────────────────────────────┐
│                    权限系统架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  工具调用请求                                                │
│     │                                                       │
│     ▼                                                       │
│  ┌─────────────────┐                                        │
│  │  1. deny 检查   │  ← 黑名单，优先级最高                   │
│  │     (拒绝列表)   │     匹配则直接拒绝                      │
│  └────────┬────────┘                                        │
│           │ 通过                                             │
│           ▼                                                 │
│  ┌─────────────────┐                                        │
│  │  2. allow 检查  │  ← 白名单                              │
│  │     (允许列表)   │     匹配则自动允许                      │
│  └────────┬────────┘                                        │
│           │ 未匹配                                           │
│           ▼                                                 │
│  ┌─────────────────┐                                        │
│  │  3. ask 检查    │  ← 询问列表                            │
│  │     (询问列表)   │     匹配则询问用户                      │
│  └────────┬────────┘                                        │
│           │ 未匹配                                           │
│           ▼                                                 │
│  ┌─────────────────┐                                        │
│  │  4. defaultMode │  ← 默认模式                            │
│  │     (默认行为)   │     acceptEdits / ask                 │
│  └─────────────────┘                                        │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  defaultMode 选项:                                          │
│                                                             │
│  ┌──────────────────┬──────────────────────────────────┐    │
│  │ "ask" (默认)      │ 每次操作都需确认，最安全          │    │
│  ├──────────────────┼──────────────────────────────────┤    │
│  │ "acceptEdits"    │ 自动接受编辑，仅高危操作询问      │    │
│  └──────────────────┴──────────────────────────────────┘    │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  权限匹配模式:                                               │
│                                                             │
│  工具调用: Bash(command="cargo run --release")              │
│                                                             │
│  ┌────────────────────────────┬─────────────────────────┐   │
│  │ 规则                        │ 匹配结果                │   │
│  ├────────────────────────────┼─────────────────────────┤   │
│  │ "Bash(cargo run:*)"        │ ✅ 允许                 │   │
│  │ "Bash(cargo:*)"            │ ✅ 允许                 │   │
│  │ "Bash(dir:*)"              │ ❌ 不匹配               │   │
│  │ "Bash(rm -rf /:*)"         │ ❌ 拒绝 (deny)          │   │
│  │ "Read(./**/.env*)"         │ ❌ 拒绝 (deny)          │   │
│  └────────────────────────────┴─────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. 提示缓存 (Prompt Caching)

```
┌─────────────────────────────────────────────────────────────┐
│              提示缓存机制与 Token 消耗                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  缓存启用 (默认):                                            │
│                                                             │
│  第 1 次请求:                                                │
│  ┌─────────────────────────────────────────────────┐        │
│  │ 系统提示词 + 上下文 + 用户输入                   │        │
│  │ 计费: 100% tokens                                │        │
│  │ ├─ 缓存写入: 80%                                 │        │
│  │ └─ 实际计费: 20%                                 │        │
│  └─────────────────────────────────────────────────┘        │
│                                                             │
│  第 2 次请求 (上下文未变):                                   │
│  ┌─────────────────────────────────────────────────┐        │
│  │ 系统提示词 + 上下文 + 用户输入                   │        │
│  │ 计费: 20% tokens (缓存命中)                      │        │
│  └─────────────────────────────────────────────────┘        │
│                                                             │
│  缓存禁用 (DISABLE_PROMPT_CACHING=1):                        │
│                                                             │
│  每次请求:                                                   │
│  ┌─────────────────────────────────────────────────┐        │
│  │ 系统提示词 + 上下文 + 用户输入                   │        │
│  │ 计费: 100% tokens (无缓存)                       │        │
│  └─────────────────────────────────────────────────┘        │
│                                                             │
│  配置:                                                       │
│  "env": { "DISABLE_PROMPT_CACHING": "1" }   // 全局禁用      │
│  "env": { "DISABLE_PROMPT_CACHING_OPUS": "1" }  // 禁用 Opus │
│  "env": { "DISABLE_PROMPT_CACHING_SONNET": "1" } // 禁用 Sonnet│
│                                                             │
│  成本对比 (假设上下文 10000 tokens):                         │
│  ┌──────────────┬─────────────────┬─────────────────┐       │
│  │              │   第 1 次请求    │   第 2 次请求    │       │
│  ├──────────────┼─────────────────┼─────────────────┤       │
│  │ 启用缓存      │    $0.30        │    $0.06        │       │
│  │ 禁用缓存      │    $0.30        │    $0.30        │       │
│  └──────────────┴─────────────────┴─────────────────┘       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 快速参考

### 当前项目配置

```json
{
  "model": "opus",                                    // 最强模型
  "alwaysThinkingEnabled": true,                      // 启用扩展思考
  "permissions": {
    "defaultMode": "acceptEdits"                      // 自动接受编辑
  },
  "sandbox": {
    "enabled": true,
    "autoAllowBashIfSandboxed": true                  // 自动允许沙盒
  },
  "env": {
    "MAX_THINKING_TOKENS": "31999",                   // 最大思考
    "CLAUDE_CODE_MAX_OUTPUT_TOKENS": "8192",          // 增加输出
    "DISABLE_PROMPT_CACHING": "1",                    // 禁用缓存
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",  // 禁用非必要流量
    "CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR": "1"    // 保持工作目录
  }
}
```
